## UX flow
1. **Open sidebar, click Tasks** — Navigate to /tasks within the authenticated shell; sidebar highlights active entry
2. **View task list on first load** — Loading skeleton, then either populated list or empty-state CTA 'Add your first task'
3. **Click Add Task** — modals-add-task.tsx dialog opens with title field focused, optional due date
4. **Submit new task** — Modal closes, task appears at top/relevant position without page refresh
5. **Check the completion checkbox** — Task shows completed styling immediately; state persists on reload
6. **Edit then delete a task** — Edit reopens modal prefilled; delete removes row after confirm

## Edge cases & invariants
- powerTasks.ts contains only a schema/table but no CRUD functions — implementer must add list/create/update/remove mutations before UI works.
- Task with no due date — must render cleanly (no 'Invalid Date' from date-fns; guard null before format()).
- Concurrent edit: two tabs open, one deletes a task another is editing — Convex reactivity should collapse the row; edit modal must handle target-gone gracefully.
- Auth identity absent (session expired) — query must not leak all users' tasks; server returns empty or throws auth error.
- modals-add-task.tsx may be hardcoded to a pillarId or a shape that no longer matches; reusing it may require decoupling finance/pillar assumptions.
- **Don't break:** If Convex auth is NOT actually wired in this repo, server-side userId scoping is impossible and every user sees every task — hard blocker, must confirm auth before shipping.
- **Don't break:** If modals-add-task.tsx assumes a pillarId prop, reusing it without decoupling silently ties 'standalone' tasks to the finance/pillars domain the author explicitly rejected.
- **Don't break:** Hand-editing routeTree.gen.ts to add the route breaks TanStack codegen and future route additions.
- **Don't break:** Rendering fields absent from schema.ts (e.g., tags/priority if not present) will fail Convex validation on write.
- **Don't break:** The auto-generated `packages/db/convex/_generated/api` type definitions mismatch if frontend development outpaces backend deployment; enforce `bun turbo run dev` so the Convex CLI regenerates schema types simultaneously.
